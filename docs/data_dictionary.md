## Notes

- Every ACS-derived column name encodes its 5-year window explicitly (e.g., `_2011_2015`) rather than a bare year, per the research protocol's alignment rule — this prevents downstream code from silently treating a rolling average as a point-in-time value.
- CHR&R-derived columns are merged using each measure's CHR&R-documented **measurement year**, which is tracked internally as a separate `{variable}_measurement_year` field so the true source year is always auditable, not inferred from the release year.
- This dictionary will be regenerated with actual observed missingness rates, MOE distributions, and final column names once `src/cleaning/*.py` is implemented — the "status" column exists specifically to keep this document from silently going stale.
